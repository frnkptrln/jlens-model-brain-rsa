# Results included here

This repository contains only compact derived outputs from the targeted-ROI
experiment:

- `confirmatory/` contains participant- and group-level preregistered RSA
  contrasts and the analysis manifest.
- `extension/` contains exploratory prompt, layer, and normalization summaries.
- `diagnostics/` contains the compact singular-value summary used for the dense
  transport diagnostic.

Large model RDMs, caption records, neural RDMs, and raw NSD responses are not
included. `provenance/validation-manifest.json` records hashes for the validated
local artifacts without redistributing access-controlled data.
