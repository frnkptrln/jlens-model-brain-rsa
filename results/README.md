# Results included here

This repository contains only compact, derived outputs used to inspect the
reported statistics and regenerate the combined paper figure.

- `study_a/layer_summary.csv` transcribes the public group-level layer summary
  from the pinned Study A repository.
- `study_b/confirmatory/` contains participant- and group-level preregistered
  RSA contrasts and the corresponding analysis manifest.
- `study_b/extension/` contains the exploratory prompt, layer, and normalization
  summaries.
- `study_b/diagnostics/` contains the small singular-value summary used for the
  dense-transport diagnostic.

Large model RDMs, caption records, neural RDMs, and raw NSD responses are not
included. The Study B provenance manifest records hashes for the validated local
artifacts without redistributing access-controlled data.
